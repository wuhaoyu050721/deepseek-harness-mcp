# 0.3.1 验证范围

验证日期：2026-10-10。环境为 Windows、Python 3.14.7、MCP 2.3.0、Harness SDK 0.1.5rc1、已安装桌面 runtime 0.2.0-rc.2。声明支持 Python 3.11–3.14，其他 Python 版本没有实际运行验收。

## 本次发布检查

最终源码回归：**499 项测试 + 27 个子测试通过**，JUnit 共 526 项，失败、错误、跳过均为 0。包含 34 项发布打包回归和 4 项源码 ZIP 初始化回归，以及已有的权限、快照、脱敏、任务、进程与报告检查。没有提交模型任务。

发布打包检查覆盖：固定文件清单、私人数据排除、路径规范与大小写冲突、软链接/reparse/hardlink 拒绝、读取与收集阶段文件漂移、ZIP 回读字节、wheel 模块集合与源码逐字节匹配、幂等资产写入。源码包和 Skill 包使用固定 ZIP 时间戳，生成成员摘要与 SHA256SUMS。

源码 ZIP 在没有 `.git` 的全新目录中解压，使用新的 `.venv` 和锁文件完成依赖安装（本机缓存离线），初始化成功，只授权人工 `sample` 项目。桌面前置检查通过，官方 Python MCP 客户端握手并发现四工具，核对 `mode` 支持 review/edit。没有调用模型，个人客户端配置哈希未变。最终包中的运行模块、初始化脚本、通用配置与锁文件按已验收成员摘要再次匹配。

公开包不包含 `data/phase0` 中本机留存的官方 SDK wheel 协议测试夹具。从发布包重跑测试时，`test_official_sdk_stdio_wire_activity_against_artificial_runtime` 会在该可选夹具缺失时明确 skip；这不等于同样取得本机的“0 跳过”结果。其余依赖外部程序/系统能力的检查需满足各自前置条件。

## 同版本服务的既有真实验收

打包前的安全修复验收已通过 461 项测试和 27 个子测试，并通过正式 stdio 协议、客户端发现、doctor 和 wheel 构建。SEC-01 至 SEC-05、硬链接和机械补丁加固均映射到实际通过的测试。公开摘要保留该映射以及全部服务模块 SHA256；发布时模块摘要与真实模型验收对应版本的记录一致。

Codex CLI 0.162.0-alpha.17.2 与 Claude Code 2.1.273 均完成控制通道握手和四工具发现；这一阶段没有模型请求。正式协议验证覆盖 stdout 仅 JSON-RPC、stdin EOF 退出、四工具、幂等、锁与明确缺少后端的失败路径。

0.3.1 已经由独立新 Codex 连接通过公开四工具提交一次真实桌面副本编辑。人工 `calculator.py` 任务成功，完整差异和修改后内容可重建，baseline/副本/报告摘要一致，原项目未改变。同编号重放没有新增执行，终态取消保持成功，桌面与 Codex 进程树停止、专用 home 清理、个人配置不变均通过。

这次生成样例只进行 AST 和内容复核，**没有执行或合入生成代码**。报告 `tests=not_run`；固定不运行命令的提示和模型报告不能独立证明所有命令从未执行。原始本机路径、任务编号、个人配置摘要和模型原文不发布，公开摘要只保留检查项目、状态和范围。本次打包没有重复付费模型调用。

## 尚未验证或不提供的保证

- Windows desktop 没有操作系统级文件或网络沙箱；独立副本与 JobObject 分别提供任务目录和进程生命周期管理。
- 可选 Docker 镜像实际构建与容器隔离、Linux/macOS runtime、Python 3.11–3.13 实际运行、Claude 完整模型流程尚未验收。
- 活动模型请求取消和服务商停止计费尚未验收；本机进程停止不证明上游计费停止。
- 当前 GUI 热加载没有验收。更新后重新连接或重启客户端，再核对实时工具参数。
